# Задача 51 - Максимумы строк матрицы

## 1. Идея решения и структура данных

Вход хранится в `int[][] a`, результаты - в `int[] res` длины `n`. Для каждой строки максимум сначала берётся из её первого элемента, а не из нуля, чтобы правильно обработать отрицательные числа

Основной код из метода `solve`:

```java
int[] res = new int[a.length];
for (int i = 0; i < a.length; i++) {
    int max = a[i][0];
    for (int x : a[i]) if (x > max) max = x;
    res[i] = max;
}
return res;
```

Перебираются все элементы всех строк, каждый сравнивается с текущим максимумом. Для каждой из `n` строк сохраняется одно число

## 2. Анализ асимптотики

**Временная сложность `solve`: `O(nm)`**

**Дополнительная память `solve`: `O(n)`**

Обоснование по приведённому коду: Перебираются все элементы всех строк, каждый сравнивается с текущим максимумом. Для каждой из `n` строк сохраняется одно число

Здесь `n` - число строк, `m` - число столбцов. Оценки относятся к методу `solve` и не включают хранение матрицы, уже переданной как параметр. Если программа сначала считывает матрицу из стандартного ввода, чтение и хранение входных данных требуют `O(nm)` времени и памяти (для задач с матрицей фиксированного размера 3 на 3 - `O(1)`). У задачи 58 память выходной матрицы уже включена в оценку.

## 3. Ручные тесты

В примерах символ `/` отделяет строки ввода или вывода, в консоли вместо него используется переход на новую строку. Для случаев с пометкой `solve` тестируется прямой вызов метода, а не ввод из консоли.

| Случай | Входные данные | Ожидаемый результат | Что проверяем |
|---|---|---|---|
| Обычная матрица | `2 3 / 1 2 3 / 4 5 6` | `3 6` | Поиск максимума |
| Только отрицательные числа | `1 3 / -8 -2 -5` | `-2` | Нельзя начинать максимум с нуля |
| Все равны | `1 3 / 4 4 4` | `4` | Совпадающие числа |
| Один элемент | `1 1 / -7` | `-7` | Минимальный размер |
| Один столбец | `2 1 / 5 / -1` | `5 -1` | Один элемент в каждой строке |
| Крайние int | `1 2 / -2147483648 2147483647` | `2147483647` | Граничные значения |
| Рваная матрица (solve) | `new int[][] {{1, 2}, {3}}` | `IllegalArgumentException` | Проверка формы |
