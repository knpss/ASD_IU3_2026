# Задача 52 - Минимумы столбцов матрицы

## 1. Идея решения и структура данных

Вход хранится в `int[][] a`, результаты - в `int[] res` длины `m`. В качестве начальных минимумов копируется первая строка через `clone()`, поэтому исходная матрица не изменяется

Используется следующий фрагмент метода `solve`:

```java
int[] res = a[0].clone();
for (int i = 1; i < a.length; i++) {
    for (int j = 0; j < res.length; j++) {
        if (a[i][j] < res[j]) res[j] = a[i][j];
    }
}
return res;
```

## 2. Анализ асимптотики

Временная сложность `solve`: **`O(nm)`**

Дополнительная память `solve`: **`O(m)`**

Обоснование по коду:

- `int[] res = a[0].clone()` копирует m значений первой строки, не меняя входной массив
- `for (int i = 1; i < a.length; i++)` обходит остальные n-1 строк, внутренний цикл перебирает m столбцов
- `if (a[i][j] < res[j])` обновляет минимум столбца только при меньшем значении

Если учитывать чтение всей входной матрицы в `run`, время и память составят `O(nm)`

## 3. Ручные тесты

В примерах символ `/` отделяет строки ввода или вывода, в консоли вместо него используется переход на новую строку. Для случаев с пометкой `solve` тестируется прямой вызов метода, а не ввод из консоли.

| Случай | Входные данные | Ожидаемый результат | Что проверяем |
|---|---|---|---|
| Обычная матрица | `2 3 / 1 2 3 / 4 5 6` | `1 2 3` | Минимумы находятся в первой строке |
| Минимум во второй строке | `2 3 / 5 -1 7 / 3 4 -2` | `3 -1 -2` | Обновление отдельных минимумов |
| Одна строка | `1 3 / 8 0 -9` | `8 0 -9` | Возврат копии строки |
| Один столбец | `3 1 / 4 / -2 / 7` | `-2` | Массив из одного результата |
| Равные значения | `2 2 / 3 3 / 3 3` | `3 3` | Равные минимумы |
| Граничные int | `2 1 / 2147483647 / -2147483648` | `-2147483648` | Сравнение предельных значений |
| Пустая матрица (solve) | `new int[0][]` | `IllegalArgumentException` | Защита от пустого массива |

В таблице разобраны обычные случаи, границы размеров, значения и ошибочные входные данные. Они соответствуют проверкам в JUnit. Покрытие строк измеряется отдельно командой `mvn clean verify` через JaCoCo, а не по числу строк в таблице
