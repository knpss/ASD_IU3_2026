# Задача 55 - Сумма побочной диагонали

## 1. Идея решения и структура данных

Вход хранится в `int[][] a`. Дополнительный массив не нужен: используются `int n` и `long sum`. Матрица должна быть квадратной. Индексы `a[i][n - i - 1]` выбирают побочную диагональ

Основной код из метода `solve`:

```java
long sum = 0;
int n = a.length;
for (int i = 0; i < n; i++) sum += a[i][n - i - 1];
return sum;
```

После проверки формы матрицы метод делает `n` сложений по одному элементу побочной диагонали. Дополнительно используются несколько переменных. Проверка `check` занимает `O(n)` по количеству строк

## 2. Анализ асимптотики

**Временная сложность `solve`: `O(n)`**

**Дополнительная память `solve`: `O(1)`**

Обоснование по приведённому коду: После проверки формы матрицы метод делает `n` сложений по одному элементу побочной диагонали. Дополнительно используются несколько переменных. Проверка `check` занимает `O(n)` по количеству строк

Здесь `n` - число строк, `m` - число столбцов. Оценки относятся к методу `solve` и не включают хранение матрицы, уже переданной как параметр. Если программа сначала считывает матрицу из стандартного ввода, чтение и хранение входных данных требуют `O(nm)` времени и памяти (для задач с матрицей фиксированного размера 3 на 3 - `O(1)`). У задачи 58 память выходной матрицы уже включена в оценку.

## 3. Ручные тесты

В примерах символ `/` отделяет строки ввода или вывода, в консоли вместо него используется переход на новую строку. Для случаев с пометкой `solve` тестируется прямой вызов метода, а не ввод из консоли.

| Случай | Входные данные | Ожидаемый результат | Что проверяем |
|---|---|---|---|
| Обычная квадратная | `3 3 / 1 2 3 / 4 5 6 / 7 8 9` | `15` | Сумма 3+5+7 |
| Один элемент | `1 1 / -8` | `-8` | Минимальная матрица |
| Отрицательные элементы | `2 2 / -1 2 / 3 -5` | `5` | Сумма 2+3 |
| Нули на побочной диагонали | `2 2 / 2147483647 0 / 0 2147483647` | `0` | Не путать с главной диагональю |
| Прямоугольная | `2 3 / 1 2 3 / 4 5 6` | `IllegalArgumentException` | Проверка квадратной формы |
| Рваная (solve) | `new int[][] {{1,2},{3}}` | `IllegalArgumentException` | Проверка формы массива |
