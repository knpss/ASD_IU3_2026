# Задача 50 - Суммы столбцов матрицы

## 1. Идея решения и структура данных

Используется входной двумерный массив `int[][] a` и массив `long[] res` длины `m`. Элемент `res[j]` хранит текущую сумму j-го столбца. Значения накапливаются при обходе всех строк

Используется следующий фрагмент метода `solve`:

```java
long[] res = new long[a[0].length];
for (int[] row : a) {
    for (int j = 0; j < res.length; j++) res[j] += row[j];
}
return res;
```

## 2. Анализ асимптотики

Временная сложность `solve`: **`O(nm)`**

Дополнительная память `solve`: **`O(m)`**

Обоснование по коду:

- `long[] res = new long[a[0].length]` выделяет m ячеек по числу столбцов
- `for (int[] row : a)` выполняется n раз, а цикл по `j` проходит m столбцов
- `res[j] += row[j]` добавляет текущий элемент к сумме столбца j

Если учитывать чтение всей входной матрицы в `run`, время и память составят `O(nm)`

## 3. Ручные тесты

В примерах символ `/` отделяет строки ввода или вывода, в консоли вместо него используется переход на новую строку. Для случаев с пометкой `solve` тестируется прямой вызов метода, а не ввод из консоли.

| Случай | Входные данные | Ожидаемый результат | Что проверяем |
|---|---|---|---|
| Обычная матрица 2 на 3 | `2 3 / 1 2 3 / 4 5 6` | `5 7 9` | Сумма по каждому столбцу |
| Отрицательные и нули | `2 3 / -2 1 -3 / 0 0 0` | `-2 1 -3` | Отрицательные значения |
| Одна строка | `1 3 / 7 -8 9` | `7 -8 9` | Один элемент в каждом столбце |
| Один столбец | `3 1 / 1 / 2 / -4` | `-1` | Один ответ |
| Граничные int | `2 1 / 2147483647 / 2147483647` | `4294967294` | Сумма больше int |
| Некорректная матрица (solve) | `new int[][] {{1}, null}` | `IllegalArgumentException` | Проверка null-строки |
| Нулевой размер | `2 0` | `IllegalArgumentException` | Отказ при нулевом количестве столбцов |

В таблице разобраны обычные случаи, границы размеров, значения и ошибочные входные данные. Они соответствуют проверкам в JUnit. Покрытие строк измеряется отдельно командой `mvn clean verify` через JaCoCo, а не по числу строк в таблице
