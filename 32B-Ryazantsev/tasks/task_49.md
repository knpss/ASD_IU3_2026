# Задача 49 - Суммы строк матрицы

## 1. Идея решения и структура данных

Используется входной двумерный массив `int[][] a` и одномерный массив `long[] res` длины `n`. В `res[i]` записывается сумма i-й строки. Тип `long` выбран потому, что сумма нескольких `int` может не поместиться в `int`

Используется следующий фрагмент метода `solve`:

```java
long[] res = new long[a.length];
for (int i = 0; i < a.length; i++) {
    long sum = 0;
    for (int x : a[i]) sum += x;
    res[i] = sum;
}
return res;
```

## 2. Анализ асимптотики

Временная сложность `solve`: **`O(nm)`**

Дополнительная память `solve`: **`O(n)`**

Обоснование по коду:

- `long[] res = new long[a.length]` выделяет n элементов под результаты по строкам
- `for (int i = 0; i < a.length; i++)` проходит n строк, а `for (int x : a[i])` просматривает m элементов каждой строки
- `sum` хранит текущую сумму, а `res[i] = sum` сохраняет результат для строки i

Если учитывать чтение всей входной матрицы в `run`, время и память составят `O(nm)`

## 3. Ручные тесты

В примерах символ `/` отделяет строки ввода или вывода, в консоли вместо него используется переход на новую строку. Для случаев с пометкой `solve` тестируется прямой вызов метода, а не ввод из консоли.

| Случай | Входные данные | Ожидаемый результат | Что проверяем |
|---|---|---|---|
| Обычная матрица 2 на 3 | `2 3 / 1 2 3 / 4 5 6` | `6 15` | Разные суммы по строкам |
| Отрицательные и нули | `2 3 / -2 1 -3 / 0 0 0` | `-4 0` | Знак и нулевые суммы |
| Один элемент | `1 1 / -7` | `-7` | Минимальный размер |
| Один столбец | `3 1 / 5 / -2 / 0` | `5 -2 0` | Длина ответа по строкам |
| Переполнение int | `1 2 / 2147483647 2147483647` | `4294967294` | Использование long |
| Некорректные размеры | `0 2` | `IllegalArgumentException` | Отказ при нулевом количестве строк |
| Рваная матрица (прямой вызов solve) | `new int[][] {{1, 2}, {3}}` | `IllegalArgumentException` | Проверка формы массива |

В таблице разобраны обычные случаи, границы размеров, значения и ошибочные входные данные. Они соответствуют проверкам в JUnit. Покрытие строк измеряется отдельно командой `mvn clean verify` через JaCoCo, а не по числу строк в таблице
