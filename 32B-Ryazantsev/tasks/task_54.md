# Задача 54 - Сумма главной диагонали

## 1. Идея решения и структура данных

Вход хранится в `int[][] a`. Дополнительный массив не нужен: достаточно переменной `long sum`. Матрица должна быть квадратной. Индексы `a[i][i]` выбирают главную диагональ

Основной код из метода `solve`:

```java
if (a.length != a[0].length) throw new IllegalArgumentException("Не квадратная матрица");
long sum = 0;
for (int i = 0; i < a.length; i++) sum += a[i][i];
return sum;
```

После проверки формы матрицы метод делает `n` сложений по одному элементу диагонали. Дополнительно использует только сумму и индекс цикла. Сама проверка `check` тоже обходит `n` строк

## 2. Анализ асимптотики

**Временная сложность `solve`: `O(n)`**

**Дополнительная память `solve`: `O(1)`**

Обоснование по приведённому коду: После проверки формы матрицы метод делает `n` сложений по одному элементу диагонали. Дополнительно использует только сумму и индекс цикла. Сама проверка `check` тоже обходит `n` строк

Здесь `n` - число строк, `m` - число столбцов. Оценки относятся к методу `solve` и не включают хранение матрицы, уже переданной как параметр. Если программа сначала считывает матрицу из стандартного ввода, чтение и хранение входных данных требуют `O(nm)` времени и памяти (для задач с матрицей фиксированного размера 3 на 3 - `O(1)`). У задачи 58 память выходной матрицы уже включена в оценку.

## 3. Ручные тесты

В примерах символ `/` отделяет строки ввода или вывода, в консоли вместо него используется переход на новую строку. Для случаев с пометкой `solve` тестируется прямой вызов метода, а не ввод из консоли.

| Случай | Входные данные | Ожидаемый результат | Что проверяем |
|---|---|---|---|
| Обычная квадратная | `3 3 / 1 2 3 / 4 5 6 / 7 8 9` | `15` | Сумма 1+5+9 |
| Один элемент | `1 1 / -8` | `-8` | Минимальная квадратная матрица |
| Отрицательная диагональ | `2 2 / -1 2 / 3 -5` | `-6` | Сложение отрицательных |
| Большая сумма | `2 2 / 2147483647 0 / 0 2147483647` | `4294967294` | Выход суммы за int |
| Прямоугольная | `2 3 / 1 2 3 / 4 5 6` | `IllegalArgumentException` | Проверка квадратной формы |
| Null-строка (solve) | `new int[][] {{1, 2}, null}` | `IllegalArgumentException` | Проверка корректности входа |
