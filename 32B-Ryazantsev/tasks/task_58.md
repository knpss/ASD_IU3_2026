# Задача 58 - Заполнение матрицы змейкой

## 1. Идея решения и структура данных

Метод получает размеры `n` и `m`, создаёт `int[][] a` и записывает в него числа от 1 до `n*m`. Дополнительные списки и перестановки не нужны. Для строк с чётным индексом направление слева направо, с нечётным - справа налево

Основной код из метода `solve`:

```java
int[][] a = new int[n][m];
int num = 1;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        int col = i % 2 == 0 ? j : m - j - 1;
        a[i][col] = num++;
    }
}
return a;
```

Два вложенных цикла выполняют по одной записи для каждой из `n*m` ячеек. Матрица ответа содержит `n*m` значений. Условие в цикле выбирает направление, но не добавляет нового обхода

## 2. Анализ асимптотики

**Временная сложность `solve`: `O(nm)`**

**Дополнительная память `solve`: `O(nm)`**

Обоснование по приведённому коду: Два вложенных цикла выполняют по одной записи для каждой из `n*m` ячеек. Матрица ответа содержит `n*m` значений. Условие в цикле выбирает направление, но не добавляет нового обхода

Здесь `n` - число строк, `m` - число столбцов. Оценки относятся к методу `solve` и не включают хранение матрицы, уже переданной как параметр. Если программа сначала считывает матрицу из стандартного ввода, чтение и хранение входных данных требуют `O(nm)` времени и памяти (для задач с матрицей фиксированного размера 3 на 3 - `O(1)`). У задачи 58 память выходной матрицы уже включена в оценку.

## 3. Ручные тесты

В примерах символ `/` отделяет строки ввода или вывода, в консоли вместо него используется переход на новую строку. Для случаев с пометкой `solve` тестируется прямой вызов метода, а не ввод из консоли.

| Случай | Входные данные | Ожидаемый результат | Что проверяем |
|---|---|---|---|
| Матрица 2 на 3 | `2 3` | `1 2 3 / 6 5 4` | Смена направления во второй строке |
| Одна строка | `1 3` | `1 2 3` | Прямой порядок |
| Один столбец | `3 1` | `1 / 2 / 3` | Чередование при ширине 1 |
| Три строки | `3 2` | `1 2 / 4 3 / 5 6` | Возврат к прямому порядку |
| Один элемент | `1 1` | `1` | Минимальный размер |
| Нулевая высота | `0 2` | `IllegalArgumentException` | Проверка n |
| Отрицательная ширина | `2 -1` | `IllegalArgumentException` | Проверка m |
| Слишком большой массив | `100000 100000` | `IllegalArgumentException` | Проверка n*m до выделения массива |
