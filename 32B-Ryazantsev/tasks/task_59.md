# Задача 59 - Определитель матрицы 3 на 3

## 1. Идея решения и структура данных

Для 3 на 3 используется правило Саррюса. Исходные данные хранятся в `int[][] a`, а шесть произведений накапливаются в `BigInteger`. Это исключает переполнение при перемножении больших значений `int`

Основной код из метода `solve`:

```java
BigInteger p = BigInteger.ZERO;
BigInteger q = BigInteger.ZERO;
for (int i = 0; i < 3; i++) {
    BigInteger x = BigInteger.ONE;
    BigInteger y = BigInteger.ONE;
    for (int j = 0; j < 3; j++) {
        x = x.multiply(BigInteger.valueOf(a[j][(i + j) % 3]));
        y = y.multiply(BigInteger.valueOf(a[j][(i - j + 3) % 3]));
    }
    p = p.add(x);
    q = q.add(y);
}
return p.subtract(q);
```

Размер входа строго фиксирован: 3 на 3. Оба цикла выполняют по 3 итерации, всего 9 пар произведений. Число объектов `BigInteger` ограничено константой для 32-битных элементов

## 2. Анализ асимптотики

**Временная сложность `solve`: `O(1)`**

**Дополнительная память `solve`: `O(1)`**

Обоснование по приведённому коду: Размер входа строго фиксирован: 3 на 3. Оба цикла выполняют по 3 итерации, всего 9 пар произведений. Число объектов `BigInteger` ограничено константой для 32-битных элементов

Здесь `n` - число строк, `m` - число столбцов. Оценки относятся к методу `solve` и не включают хранение матрицы, уже переданной как параметр. Если программа сначала считывает матрицу из стандартного ввода, чтение и хранение входных данных требуют `O(nm)` времени и памяти (для задач с матрицей фиксированного размера 3 на 3 - `O(1)`). У задачи 58 память выходной матрицы уже включена в оценку.

## 3. Ручные тесты

В примерах символ `/` отделяет строки ввода или вывода, в консоли вместо него используется переход на новую строку. Для случаев с пометкой `solve` тестируется прямой вызов метода, а не ввод из консоли.

| Случай | Входные данные | Ожидаемый результат | Что проверяем |
|---|---|---|---|
| Единичная матрица | `3 3 / 1 0 0 / 0 1 0 / 0 0 1` | `1` | Определитель единичной матрицы |
| Отрицательный определитель | `3 3 / -2 0 0 / 0 1 0 / 0 0 1` | `-2` | Корректный знак |
| Две одинаковые строки | `3 3 / 1 2 3 / 1 2 3 / 7 8 9` | `0` | Вырожденная матрица |
| Смешанные числа | `3 3 / 2 -1 0 / 3 4 1 / 5 2 6` | `57` | Шесть произведений и вычитание |
| Большие значения | `3 3 / 2147483647 0 0 / 0 2147483647 0 / 0 0 2147483647` | `9903520300447984150353281023` | BigInteger вместо long |
| Размер 2 на 2 | `2 2 / 1 2 / 3 4` | `IllegalArgumentException` | Только 3 на 3 |
| Рваная матрица (solve) | `new int[][] {{1,2,3},{1,2,3},{1,2}}` | `IllegalArgumentException` | Проверка каждой строки |
