## Проверка

Запуск тестов и генерация отчёта JaCoCo:

```sh
mvn -pl 32B-Ryazantsev -am clean verify
```

HTML-отчёт: `32B-Ryazantsev/target/site/jacoco/index.html`

В `pom.xml` установлен порог 80% покрытия строк для каждого класса задачи. Перед отправкой надо получить `BUILD SUCCESS` на JDK 25. Проверка JaCoCo срабатывает отдельно для каждого класса

Общее сравнение асимптотики приведено в `analysis.md`
