## Задача 49 - Суммы строк матрицы

Нужно получить сумму элементов отдельно для каждой строки, порядок строк сохраняется

Основная часть решения:

```java
long[] res = new long[a.length];
for (int i = 0; i < a.length; i++) {
    long sum = 0;
    for (int x : a[i]) sum += x;
    res[i] = sum;
}
return res;
```

`res` хранит по одной сумме для каждой строки

`sum` обнуляется перед обработкой новой строки, иначе суммы нескольких строк смешались бы

Цикл `for (int x : a[i])` обходит все числа в строке `i`, после чего результат записывается в `res[i]`

Для сумм используется `long`, чтобы уменьшить риск переполнения при сложении значений `int`

Время: `O(nm)`, потому что просматриваются все `n*m` элементов

Память: `O(n)` под массив ответов, без входной матрицы

Пример: `2 3 / 1 2 3 / 4 5 6 -> 6 15`

В тестах также проверяются отрицательные числа, большие суммы, один столбец и некорректная форма матрицы

## Задача 50 - Суммы столбцов матрицы

Нужно сложить все значения каждого столбца, ответ содержит `m` чисел

Основная часть решения:

```java
long[] res = new long[a[0].length];
for (int[] row : a) {
    for (int j = 0; j < res.length; j++) res[j] += row[j];
}
return res;
```

`res[j]` - текущая сумма столбца с индексом `j`

Внешний цикл перебирает строки, внутренний цикл прибавляет значения этих строк к нужным столбцам

Массив изначально заполнен нулями, поэтому дополнительная инициализация сумм не нужна

Время: `O(nm)`, обходим всю матрицу

Память: `O(m)` для массива сумм, без входной матрицы

Пример: `2 3 / 1 2 3 / 4 5 6 -> 5 7 9`

В тестах также проверяются одна строка, отрицательные элементы и некорректные размеры

## Задача 51 - Максимумы строк матрицы

Пример: `2 3 / 1 2 3 / 4 5 6 -> 3 6`
