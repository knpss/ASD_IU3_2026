# Отчёт по лабораторной работе №1

Рязанцев, группа ИУ3-32Б

Всего выполнено восемь задач из раздела матриц, по три балла каждая - 24 балла

## Задача 49 - Суммы строк матрицы

Для каждой строки складываются все её элементы

Время `O(nm)`, память `O(n)` без учёта матрицы для ввода

Пример: `2 3 / 1 2 3 / 4 5 6 -> 6 15`

## Задача 50 - Суммы столбцов матрицы

Для каждого столбца отдельно накапливается сумма

Время `O(nm)`, память `O(m)` без учёта матрицы для ввода

Пример: `2 3 / 1 2 3 / 4 5 6 -> 5 7 9`

## Задача 51 - Максимумы строк матрицы

Для каждой строки ищется самый большой элемент

Время `O(nm)`, память `O(n)` без учёта матрицы для ввода

Пример: `2 3 / 1 2 3 / 4 5 6 -> 3 6`

## Задача 52 - Минимумы столбцов матрицы

Минимумы сравниваются по столбцам

Время `O(nm)`, память `O(m)` без учёта матрицы для ввода

Пример: `2 3 / 1 2 3 / 4 5 6 -> 1 2 3`

## Задача 54 - Сумма главной диагонали

Суммируются элементы с одинаковыми индексами строки и столбца

Время `O(n)`, память `O(1)` без учёта матрицы для ввода

Пример: `3 3 / 1 2 3 / 4 5 6 / 7 8 9 -> 15`

## Задача 55 - Сумма побочной диагонали

Суммируются элементы с индексами `(i, n-1-i)`

Время `O(n)`, память `O(1)` без учёта матрицы для ввода

Пример: `3 3 / 1 2 3 / 4 5 6 / 7 8 9 -> 15`

## Задача 58 - Заполнение матрицы змейкой

Чётные строки заполняются слева направо, нечётные - справа налево

Время `O(nm)`, память `O(nm)` без учёта матрицы для ввода

Пример: `2 3 -> 1 2 3 / 6 5 4`

## Задача 59 - Определитель матрицы 3 на 3

Определитель вычисляется по правилу Саррюса

Время `O(1)`, память `O(1)` без учёта матрицы для ввода

Пример: `3 3 / 1 0 0 / 0 1 0 / 0 0 1 -> 1`
