# ЛР 1 - Рязанцев, ИУ3-32Б

Выполненные задачи: 49, 50, 51, 52, 54, 55, 58, 59

Каждая задача находится в отдельном пакете `task_XX` и имеет свой `main`
Промежуточной папки `common` нет

Ввод: сначала размеры `n m`, затем `n*m` целых чисел по строкам
Для задач 54 и 55 матрица квадратная, для задачи 59 - ровно `3 3`
Для задачи 58 вводятся только `n m`, а матрица строится программой
Вывод: одно значение, одна строка чисел либо матрица построчно

Запуск тестов из корня репозитория:

```sh
mvn -pl 32B-Ryazantsev -am clean verify
```

Для отдельной задачи, например №49:

```sh
java -cp 32B-Ryazantsev/target/classes ru.bmstu.lab01.task_49.Task49
```

Подробности по сложности в `analysis.md`, примеры и комментарии в `report.md`

Для каждой задачи есть отдельный файл с тремя пунктами: идея и структура данных,
анализ времени и памяти с кодом, ручные тесты с ожидаемыми ответами

JaCoCo проверяет минимум 80% строк **каждого** класса задачи при `mvn clean verify`
