# Расчёт асимптотики

`n` - число строк, `m` - число столбцов

| Задача | Время алгоритма | Дополнительная память |
|---|---|---|
| 49 | `O(nm)` | `O(n)` |
| 50 | `O(nm)` | `O(m)` |
| 51 | `O(nm)` | `O(n)` |
| 52 | `O(nm)` | `O(m)` |
| 54 | `O(n)` | `O(1)` |
| 55 | `O(n)` | `O(1)` |
| 58 | `O(nm)` | `O(nm)` |
| 59 | `O(1)` | `O(1)` |

Задачи 49-52 проходят по элементам матрицы
Задачи 54 и 55 читают только одну диагональ
Задача 58 заполняет каждый элемент один раз
Задача 59 работает ровно с девятью значениями, поэтому размер фиксирован

При чтении матрицы через `Scanner` для задач 49-55 и 59 выделяется `O(nm)` памяти
Для 59 результат хранится в `BigInteger`, чтобы не получить переполнение трёх произведений `int`
У задач 49 и 50 используется `long` для сумм, чтобы избежать переполнения `int`
